Welcome to the playground! This is a tutorial task where you can practice coding with our AI assistant.

For the rest of the game-based website tasks, you can hit the dropdown at the top of the Assistant Pane and choose between three different modes for our AI: Agent (default), Ask, and Brainstorm.

  • In Agent mode, you can prompt the AI assistant to the right of the code editor make changes directly to your codebase.
  • In Ask mode, the agent can answer questions about your code but cannot make any edits.
  • In Brainstorm mode, you can prompt the AI assistant to come up with ideas for your game.

To get familiar with the interface, try prompting the AI assistant in any of three modes to make a simple game called "Click the Box":

  • Change the header on this page to display the name of the game
  • Make the button on the screen look nicer and say "Click Me!"
  • Add a scoreboard that tracks how many times the button has been clicked
  • Add a winning game message and restart button if the score reaches 10

Once you're done, click on the Submit / Finish Tutorial button to finish the tutorial. You'll add a project title + description and answer some questions, then you can move on to the main website tasks.

Note: If you refresh the page, your changes will be lost. This is not the case for the other tasks you will be completing: your work will be saved automatically.
