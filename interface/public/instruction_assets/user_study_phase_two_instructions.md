# Phase 2: Open-Ended Game Tasks

You have completed all required website recreation tasks for Phase 1.

Before continuing, please either watch the video below (recommended) or scroll through this entire page.

![Video Instructions](instruction_assets/instructions.mp4)

<br />

### What Changes in Phase 2

You now unlock the open-ended game tasks in VibeJam (for example: "Make any Platformer game").

Compared to the website requirement tasks, these tasks are more open-ended and give you more freedom to design the final experience.

<br />

### What Stays the Same

- You still build in the same editor and preview interface.
- You still submit projects from the task page.
- The AI assistant remains available and can edit your code.
- You can continue iterating after submission and resubmit as needed.

<br />

### Quick Reminder

Use the task instructions as your source of truth for scope and constraints.

If you run into issues, use the Report flow in the interface and continue to make good-faith submissions.

<br />

When you are ready, click **Continue to Phase 2** to start the required game tasks.
